# Agent instructions

- Work issue by issue from https://github.com/jusso-dev/sentinel-detections-au/issues, priority:p1 first.
- One branch and one pull request per issue, `Closes #N` in the PR body. Merge only when CI is green (squash merge).
- Use `gh` as jusso-dev. Do not force push to main.
- Follow CONTRIBUTING.md style rules: Australian English, no em dashes, no emojis, official links, no endorsement claims, no real tenant ids or secrets.
- Read-only by design where the issue says so. Never write to a real tenant.
